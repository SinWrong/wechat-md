# prompts/ —— 文案生成提示词

| 文件 | 用途 |
| --- | --- |
| [公众号文案生成提示词.md](公众号文案生成提示词.md) | **主提示词**：完整版，含输出示例、语法速查、7 条使用建议、常见翻车与修法、一句话版 |
| [公众号文案生成提示词-精简版.md](公众号文案生成提示词-精简版.md) | **精简版**：一屏能放下，适合贴进对话框或存成快捷短语 |

两个版本语法完全一致，区别只在解释的详略：给模型看，精简版就够；给团队新人看，用完整版。

## 怎么用

1. 复制提示词，把末尾 `{{主题}}` `{{素材}}` 这些占位符换成你的内容；
2. 发给任意大模型，让它**只输出 Markdown 正文**；
3. 把输出保存为 `xxx_文案.md`；
4. 先跑校验：`python tools/check_prompt_output.py xxx_文案.md`；
5. 再用 `wechat_md_gui.bat` 打开，或 `python tools/wechat_md.py xxx_文案.md --summary` 生成模板。

## 提示词约束了什么

提示词不是"语气描述"，而是一份**格式契约**。它把程序认的每一种元素都写成了明确的写法：

- 标题、结论卡、小节编号、正文段长、加粗上限、列表、引用、图片标记、`[CTA]`、`[END]`、收尾段；
- 同时列出 7 类常见错误（重复编号、中文编号、超长段落、emoji 小标题、三连关注……），让模型主动避开。

## 和程序版本的关系

- 适用 `wechat_md` 1.1 / 编辑器 1.0；
- 语法以 [../tools/README.md](../tools/README.md) 第 3 章「文案怎么写」为准；
- 校验器规则见 [../tools/check_prompt_output.py](../tools/check_prompt_output.py)，改语法时同步改这两处。
