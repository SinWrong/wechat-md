# 预览渲染（v4）

预览面板最终采用的结构：

```
Canvas（纵向滚动）
└─ 白色纸页 Frame（宽度 = 手机宽度，固定）
   ├─ 标题 / 信息行 / 正文 …（每个块都是整行控件，左右边距统一）
   ├─ 结论卡（浅蓝底 Frame，内容左内边距 14）
   ├─ 图片（居中 Label）+ 图注（居中）
   └─ 代码块（深色 Frame + 等宽字体）
```

## 为什么换了三次

| 版本 | 做法 | 问题 |
| --- | --- | --- |
| v1 | 一堆 Label 平铺 | 中文不换行时横向撑出容器，文字压到面板外 |
| v2 | Label + 固定宽度 | 多个 Label 并排时仍会溢出；字号用「磅」被 Tk 缩放放大 1.33 倍 |
| v3 | 单个 Text + tag | 换行对了，但 Text 的 tag 边距无法让「卡片底色」和正文左边缘对齐 |
| **v4** | **Canvas + 固定宽度纸页 Frame** | 所有块都是纸页里的整行控件，边距统一，图文天然对齐 |

## 关键点

1. **纸页宽度** = 用户选择的手机宽度，且不超过面板可用宽度；缩放后会自动收窄，不会溢出。
2. **字号用像素**（Tk 负数字号），375px 预览里的 16px 就是公众号的 16px。
3. **每块整行**：正文、标题、信息行共用同一条左边缘；小标题左侧竖条、结论卡内边距、图片居中都在纸页内部完成，不会越界。
4. **高度自适应**：`<Configure>` 里按 `winfo_reqheight()` 更新滚动区域，长文滚动流畅。
5. **打开文件时重置滚动**，不会停在上一次的中间位置。
